What I checked

  • Keyboard: every link can be reached with Tab in a sensible order. The first Tab shows "Skip to content", and focus is always clearly visible.
  • Motion: the animated background stays still when the system setting "reduce motion" is on. It pauses when scrolled out of view or in a background tab to save battery.
  • Languages: German and English with their own URLs and correct language markup, so screen readers and search engines pick the right language.
  • Privacy: fonts are served by this website itself. Loading the page contacts no other server and sets no cookies.

Bugs found and fixed

#BugCauseFix
1 axe reports "region": content outside landmarks (5 places) The top area with name and links was not a landmark Marked up the top area as <header>
2 Horizontal scrolling at 320 px width (27 px) The long German word "Anwendungsentwicklung" did not fit Automatic hyphenation for headings
3 "Test report" link led to an empty page (404) The page was linked but not created yet This page

After the fixes I ran every check again. The results above are from that second run.
